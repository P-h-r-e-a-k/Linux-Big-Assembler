A crash fix, and four more days of LBAAssembler caught up with.

## Fixed

- **Picking an island or a scene from the Location panel crashed the editor.** Choosing an entry from the
  Island or Scene box at the top of the window closed it outright; picking a scene often did nothing at all
  instead. Both are fixed. The same boxes now also narrow correctly as you type, and picking one of the
  narrowed matches opens it.

  Only the Linux build was affected, and only since 1.1.0, where those boxes became visible for the first
  time. The Scenes menu was never affected.

## New, from LBAAssembler

- **The 1996 LBA2 demo** (File > Open the LBA2 1996 demo): the demo released before the game was finished,
  converted into the retail layout so its islands, interiors and scenes can be looked at. Your game folder
  is not changed, and File > Close the 1996 demo puts it back.
- **Polar Island** (Tools > LBA2: Polar Island): LBA1's island added to LBA2 as a new island you can turn
  round. It asks before changing anything, and the same menu takes it out again.
- **Keyboard and screen-reader support** in the panel tabs and the actors-in-view list, which gained an
  open button and Enter alongside the double-click.
- Race track and island-renderer work, and the native engine's own changes.
