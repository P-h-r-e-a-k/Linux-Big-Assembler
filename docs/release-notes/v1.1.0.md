The Linux Big Assembler (LBA1 / LBA2 level editor), caught up with everything added to LBAAssembler since
the Linux port was taken: 409 files and about 33,000 lines of it.

## New in this release

- **Themes.** Light (the original), Dark, two high-contrast themes and a colour-blind-safe one, under
  File > Settings > Appearance. Switching takes effect at once, with no restart.
- **Dockable panels.** Location, Viewport, Mode, the Zones / Details / Build / Play / Script tabs and the
  Minimap each have a tab strip with close buttons, a pin for auto-hide, and a button that floats the panel
  into its own window. View > Reset panel layout puts everything back.
- **Race tracks** (Tools > LBA2: race track). Builds a drivable race track on one island or several at once,
  levelled and banked, with a pit lane, a start gantry and the track drawn on the island's holomap, plus the
  cars, the drivers and the car setup. The originals are kept, and the same button puts them back.
- **Export to 3D** (Tools > LBA1 / LBA2: export 3D models). Islands, buildings, interiors, actors, bodies,
  furniture and items as glTF, OBJ, PLY or STL, with a preview. Also runs without a window:
  `./LBAAssembler --export <folder>` — on Linux that needs no display at all, so it works over ssh.
- **Nuke a scene** (Build > Nuke this scene), **Test edits** against a scratch copy of the game folder, and
  an **asset editor**.
- **Live resolution.** A played LBA2 scene now fills the space it is given and follows it as you resize,
  instead of being letterboxed into a fixed 4:3 box.

## Known differences from the Windows build

The editor is one source tree that builds for both Linux and Windows, but a few things cannot be the same
on both:

- The 3D preview in the export window is drawn in software, because the toolkit used on Linux has no 3D
  of its own. Spinning a whole island is heavier than it is on Windows.
- Textures and the development contact sheets are written through Skia rather than Windows' own imaging,
  so contact-sheet labels use a plain pixel font.
- This build writes a debug trace to `editor.log` beside the executable. That is deliberate while the port
  is under test.

Only the Linux build is published here, and only Linux has been tested.
